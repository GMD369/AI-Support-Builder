# EmbedBot

> Build AI-powered support chatbots from your documents and embed them on any website — no coding required.

---

## What is EmbedBot?

EmbedBot lets you upload your product docs, FAQs, or knowledge base, and instantly creates a smart AI chatbot that answers customer questions. Embed it on your website in seconds with a single script tag.

---

## Features

- **Multi-format document upload** — PDF, DOCX, XLSX, Markdown, TXT
- **RAG pipeline** — documents are chunked, embedded, and stored in pgvector for semantic search
- **Groq LLM** — fast, accurate answers powered by `llama-3.3-70b-versatile`
- **Conversation memory** — bot remembers context across the last 6 messages
- **Lead capture** — optional name/email gate before visitors start chatting
- **Bot customization** — display name, welcome message, widget color
- **Analytics dashboard** — total conversations, questions per day, 7-day chart
- **Embeddable widget** — copy one script tag, works on any website
- **Multi-bot management** — create and manage multiple bots per account
